# 术语表

> 项目里同一概念只用一个叫法。**新词先登记再使用**；历史文档（`technical_solution_docs/`、
> `research/`）保留当时的叫法，引用时标注一句。禁用别名由 `readability.json` 与检查脚本守住。

| 概念 | 唯一叫法 | 禁用别名 | 一句话定义 |
| --- | --- | --- | --- |
| 整个仓库的一份快照 | **完整备份** | 完整副本、完整包、全量包 | 把整个仓库写进一个 `.lsave` 文件；它同时是更新包的起点和还原点 |
| 自某份完整备份算起的差量 | **更新包** | 增量包 | 只装这段时间里变过的文件 |
| 两份完整备份之间的差量 | **差分更新包** | 差量包、差分包 | 从一份完整备份直接到另一份 |
| 搬运用的文件 | **同步包** | 包、bundle | 一个 `.lsave` 文件，里面是完整备份或更新包 |
| 本机当前依据的完整备份 | **基准** | 基准点、基准包、站的 | 应用或导出完整备份后确定；更新包不改变它 |
| 内容的版本号 | **版本号**（第 N 版） | 世代、第 N 代 | 内容每前进一次加一 |
| 内容算出来的值 | **内容校验值** | 状态编号、指纹、stateId | 两边相同就是内容一致 |
| 存放同步包的 Git 仓库 | **远程仓库** | 货架 | 推送和拉取都走它 |
| 写包 / 把包写进仓库 | **导出 / 应用** | 留包、收包、推拉 | 导出＝写包；应用＝按包改动仓库 |
| 对方放包的地方 | **接收文件夹** | 收件箱 | 同步包文件夹里留给对方的那一段 |
| 应用后达到的版本 | **目标版本** | 落点 | 这一份包要送到的版本 |
| 把本机改动导回去 | **回传** | 回礼 | 应用之后把本机这一半导成更新包 |
| 删除 / 覆盖前的暂存 | **回收站** | 回收目录（物理目录名允许） | 需要时可以从这里恢复 |
| 按包清单完全覆盖 | **镜像** | —（技术词，保留） | 包里没有的本机文件移入回收站，仓库 = 包 |
